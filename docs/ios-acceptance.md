## 安装与冷启动

- [ ] 在 Safari 中首次联网打开，等到“离线已就绪”，记录版本号。
- [ ] 分享 → 添加到主屏幕，从图标联网启动一次，确认同样显示就绪；记录是否为独立窗口。
- [ ] 开启飞行模式并确认 Wi-Fi 关闭，关闭题库后从主屏幕重新打开；题库仍正常显示。
- [ ] 保持离线刷新、切换章节、上一题/下一题、答题翻面；记录有无空白页、布局溢出或卡住。

## 解析、记录与备份

- [ ] 离线保存 AI 解析，包含 `$a^2+b^2$`；文字和公式正常显示。
- [ ] 编辑后取消，原内容不变；再次编辑并保存，冷启动后仍在。
- [ ] 打开编辑输入框时，iPhone 键盘不遮挡输入与保存操作；收起键盘后布局恢复。
- [ ] 验证错题、复习状态与解析在关闭并重新打开后保留。
- [ ] 导出完整学习备份到“文件”，再通过恢复按钮选回该文件；确认恢复对话框和成功提示，刷新后核对内容。

## 手动更新

- [ ] 离线点击“检查更新”出现失败提示，随后仍可学习，已有解析与记录仍在。
- [ ] 恢复联网但不点更新，页面继续使用已有版本。
- [ ] 点击更新后出现“已是最新版本”或“更新完成”；若确有新版本，重新打开后版本号改变、记录保留。没有可用新版本时，这一项应记“未测”，不要修改线上文件制造故障。
